Qlib 文档
=========

本地量化研究工具：从行情与财务数据读取、表达式因子计算，到横截面因子评估和日频回测。
提供行情与财务数据管理、因子评估和回测功能，数值核心使用纯 C 和 MinGW-w64。

--------

* 首次使用：阅读 :doc:`installation` 和 :doc:`quickstart`。
* 了解功能：阅读 :doc:`overview`、:doc:`data`、:doc:`factor` 和 :doc:`backtest`。
* 查询签名：阅读 :doc:`api/index`，或使用页面左侧搜索与 :ref:`genindex`。
* 维护本站：阅读 :doc:`documentation`。
